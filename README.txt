AVANTE AFRO — SITE ESTÁTICO

Para abrir offline:
1. Abra o arquivo index.html em qualquer navegador.

Para publicar no Vercel:
1. Envie todo o conteúdo desta pasta para um repositório.
2. Importe o repositório no Vercel.
3. Em Framework Preset, escolha "Other".
4. Não informe Build Command.
5. Use "." como Output Directory, se o painel solicitar.

Observação: o formulário exibe uma confirmação local, mas não envia ou armazena dados.
